Atelier Visuels TV

Antenne

Écris un prompt, regarde l'image se dessiner, puis copie le code qui la reproduit ailleurs. Plus bas, l'atelier génère des illustrations de programmes télé dans le style tv-programs, avec leur code HTML, Node, Audience Masters ou prompt d'IA.

Prompt → image

N'importe quel prompt : Claude dessine l'image décrite en SVG vectoriel, en respectant la composition et les couleurs hex indiquées. Un prompt calibré de l'atelier (avec Seed:) passe par le moteur et redonne exactement son image.

Style TV de l'atelier

Transforme le prompt en réglages du moteur (personnages mascottes, décors TV) : rendu instantané et reproductible, affiché dans l'atelier plus bas.
